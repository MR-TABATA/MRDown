## 左右の列幅を、自分の文書に合わせられます / The side columns now fit your documents

左の文書一覧と右のアウトラインは、これまで幅が決まっていました。長いファイル名は途中で切れ、短い名前ばかりのときは余った幅がそのまま余っていました。**境界の縦線を掴んで動かせます。**

The open-documents list on the left and the outline on the right used to be fixed widths — long file names were cut off, and a project with short names left the space sitting there unused. **Now you drag the line between the columns.**

線そのものが掴みしろです。カーソルを近づけると色が変わり、掴んでいる間も変わったままなので、どこを動かしているのかが見えます。幅は覚えるので、次に開いたときも同じ姿です。

The line itself is the handle. It picks up the accent colour as the pointer nears it and keeps it while you drag, so you can see what you are moving. The width is remembered, so the app opens the way you left it.

### 元に戻すのはダブルクリックです / Double-click puts it back

行き過ぎたと思ったら、線をダブルクリックすれば既定の幅に戻ります。設定を開く必要はありません。

Dragged it somewhere unreadable? Double-click the line and it returns to its default width. No trip to Settings.

### 窓を狭めても、選んだ幅は忘れません / A narrow window borrows, it doesn't take

ウィンドウを小さくすると、列は**そのぶん譲ります**（列が本文より広くなっては本末転倒なので、常に幅の半分が上限です）。それでも保存した幅は書き換えないので、ウィンドウを広げれば選んだ幅に戻ります。

Shrink the window and the columns give way — a side column that outgrows the document defeats the point of both, so half the row is always the ceiling. The width you chose is not overwritten, so widening the window brings it straight back.
