購入後の流れ

ライセンスキーは Polar の購入者ポータルにあります。

DMG をダウンロード

Polar の購入者ポータルを開き、MrkDown App Download - install this DMG から DMG をダウンロードします。

ライセンスキーをコピー

同じポータルを下にスクロールし、MrkDown License Key - copy to app をコピーします。領収メールにはキーが載らない場合があります。

MrkDown 内で有効化

MrkDown を開き、Settings > Licenses にキーを貼り付けて Activate を押します。

AI キーは自分のものを使う

AI 利用は BYOK です。プロバイダ API キーは macOS Keychain に保存され、説明対象の Markdown テキストは、そのリクエストで選んだ AI プロバイダにだけ送られます。
