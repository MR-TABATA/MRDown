# MRDown

[English](README.md) | **日本語**

**基本は Markdown ビューア。編集も保存も新規もちゃんとできて、差分（diff）が目玉。**

きっかけは Claude Code が生成する `.md` の確認でした。重いエディタを開いて右クリックでプレビュー——が面倒で、頼んだら **2時間でビューアだけの 0.1** が。今は作り手を問わず——VSCode で書いた `.md` も——**書くエディタとは別に、読むのは MRDown**、と使い分けています。そこから「あったらいいかも」で機能が増え、気づけば他の Markdown アプリには無いこと、**AI が書き換えた差分をそのまま読む**ことまでやるようになりました。

Tauri + TypeScript 製・macOS ネイティブ。

## 特徴

- Markdown ファイル（`.md` / `.markdown` / `.txt`）を開いて表示。
- 新規作成（`⌘N`）して保存ダイアログから任意の場所へ保存。無題の文書は最初の `#` 見出しがファイル名の候補になります。
- **白紙から書き始めなくてすむテンプレート**：`⌘N` は今までどおり即座に空の文書ですが、その空のページに設計書・要件定義書のテンプレートが浮かびます。押せば骨組みが入り、無視して書き始めれば消えるので、白紙 1 枚が欲しいときに手数は増えません。組み込みの 2 つは見出しと空の表と各節の短い指示だけの「骨」で、文章は入っていません（埋まった文面は、書式の違う組織には邪魔になるだけなので）。
- **雛形は自分のものを使えます**。テンプレートは**フォルダに置いたただの `.md`** です。専用の形式も管理画面もありません（直したいときはその `.md` を開いて編集するだけ）。置き場は**リポジトリの中**（`docs/_templates/`）を推奨していて、設定 ▸ テンプレートのボタンから開いているフォルダにそのまま作れます。**開いているフォルダの `docs/_templates/` は自動で使われる**ので、リポジトリを移れば雛形も一緒に切り替わります（設定で別の場所を指定することもできます）。`{{date}}` と書いた箇所は作成日に置き換わります。リポジトリに置くと clone しただけでチーム全員に配られ、`AGENTS.md` に一行足せば AI エージェントもその書式で書くようになります（貼るだけの文面を設定からコピーできます）。
- **気に入った文書から、型だけ抜けます**：ファイル ▸「この文書から雛形を作る」で、見出し・表のヘッダー・frontmatter のキー・コメント・チェックリストを残し、本文や表の中身を落とした骨組みを作ります。**結果はどこにも保存されず、新しい文書として開きます** — 見出し直下の 1 行が節の指示なのか本文なのかは機械には決められないので、判断はあなたに残し、外したときの代償を「1 回の取り消し」に抑えています。
- 現在のファイルをシステムのゴミ箱へ削除（`⌘⌫` またはゴミ箱ボタン、確認あり）。間違えてもゴミ箱から復元できます。
- `⌘E` で編集に切り替え：**プレビューがそのままエディタに変わり**、`⌘E` でプレビューに戻ります。読んでいた段落のまま入れ替わるので、どちらも常に画面いっぱいの幅で読み書きできます。設定（`⌘,`）▸ 外観 ▸「編集時のレイアウト」で**左右に並べる**（エディタ＋ライブプレビュー、仕切りをドラッグして幅を調整）にも切り替えられます。設定 ▸ プレビューの幅は切り替え時のソース列にも効くので、広い画面では 1 か所決めれば読みも書きも同じ幅になります。`⌘S` で保存、「別名で保存…」（`⌘⇧S`）で別の場所へコピーを書き出し。
- **書きながら文書として読める編集画面**：見出しは大きく、太字は太く、`#` や ``` などの記号は消えて表示されます。チェックリストは本物のチェックボックスになり、クリックでそのまま切り替わります。画像もその場に表示。表は罫線で描かれます。**カーソルのある行だけは記号がそのまま見える**ので、直したいときにいつでも素の Markdown に手が届きます（表はセルをクリック、または `↑`/`↓` で入ると、その表だけ `|` の行に戻ります）。中身は最後までただのテキストなので、保存してもファイルは 1 バイトも変わりません。
- 文書内の検索＆置換（`⌘F`）：編集中はソースを検索して全ヒットをハイライト（現在位置を強調）、プレビューではレンダリング後のテキストを検索するのでインライン装飾をまたいだマッチも可能（例：`**bold**` を跨ぐ）。正規表現・大小区別・単語単位のトグル（記憶される）、`Enter` / `⇧Enter` で移動、編集中は1件ずつ／一括で置換（`⌘Z` で取り消し可）。
- **開いている文書をまとめて横断検索**（`⌘⇧F`、または 🔍 ボタン ▸「開いている文書を横断検索」）：ひとつの入力欄で開いている文書すべてを検索します。スペース区切りの語は**同じ行に全部が現れる行だけ**（順序は不問）にヒット。結果は文書ごとにまとまり、行番号とその行が引用されます。選ぶとその文書がエディタで開き、該当箇所が選択された状態になります。`⌘F` の入力内容は引き継がれるので、`⌘F` → `⌘⇧F` で同じ語をそのまま全文書へ広げられます。
- **履歴と差分**：保存するたび、そして**外部から書き換えられるたび**に、タイムスタンプ付きの版を静かに記録。履歴パネル（時計アイコン）で**任意の2版を選んで差分を並べて読めます**（変わった語だけを強調、無変更行は折りたたみ）。Git リポジトリなら `HEAD` も同じ一覧に並ぶので、**コミット済みとの差分**もそのまま見られます。任意の版はワンクリックでエディタに復元でき、非破壊（保存するまで何も書き込まれません）。版はアプリのデータディレクトリに保存されるので、ファイルや Git リポジトリを汚しません。**Git は無くても動きます。**
- **任意の2ファイルを比較**（`⌘⇧D`）：ファイル ▸「2つのファイルを比較…」でファイルを2つ選ぶと、版の比較とまったく同じ画面で差分を読めます。文書を開いていなくても使えます。
- **編集中に書き換えられても、どちらも失いません**：AI エージェントなどがディスク上のファイルを書き換えたとき、あなたに未保存の編集があれば、黙って上書きすることも黙って読み直すこともしません。ディスク側の版はその場で履歴に退避され、あなたの未保存編集も捨てる前に退避されます。**「最後の保存 / ディスク / 自分の編集」を3列で並べ**、双方が同じ行を別々に直したところだけを衝突として示します。版には出所（保存／外部の書き換え／コミット済みの版に戻った／退避した下書き）が記録されます。なお**どのアプリが書き換えたかは macOS が記録していないため分かりません**が、内容がコミット済みの版と一致した場合だけは Git の仕業と断定できます。
- エディタ上部の書式ツールバー：太字（`⌘B`）、斜体（`⌘I`）、見出し、リスト、引用、リンクなど。選択範囲の Markdown 記法をトグル／挿入します（`⌘Z` で取り消し可）。
- 書き味を整えるタイピング支援：リストは `Enter` で自動継続（順序付きは採番、タスクは未チェックで開始、空項目で `Enter` すると解除）、`Tab` / `⇧Tab` でインデント、`[` `(` `` ` `` は対の閉じを自動挿入（選択範囲があれば囲む）。すべて `⌘Z` で取り消せます。
- テキストを選択して URL を貼るとリンク（`[選択](url)`）に変換。画像を貼り付けると、文書と同じ場所の `assets/` に保存して `![]()` を挿入します。
- 文書のメタ情報はウィンドウ最下部のステータスバーに表示：フルパス（`~` 短縮、未保存なら先頭に ● ）と、文字数・推定読了時間（日本語は1文字ずつ、英語は語数で見積もり）。ツールバーは操作だけに専念させています。編集中は編集ペインとプレビューのスクロールが同期します。
- **読書モード**（`⌘⇧M`）：ツールバー・サイドバー・アウトラインを隠して本文を中央に。生成された `.md` を、余計なものを一切置かずに読むためのモードです。`Escape` で元に戻ります。
- **プレビューテーマ**を設定（`⌘,`）で選択：既定の MRDown の見た目に加え、GitHub ライト／GitHub ダーク。GitHub 上でどう読めるかをそのまま確認できます。
- 設定（`⌘,`）でツールバーをカスタマイズ：14 種の Markdown アクション（取り消し線、番号付き／チェックリスト、コードブロック、画像、表、水平線 …）のオン／オフを切替（選択は記憶されます）。
- 日本語／英語 UI：既定では OS の言語に従い、設定で切替可能。ネイティブメニュー（File / Edit / View）もローカライズ済み。
- 外観を設定（`⌘,`）でカスタマイズ：アクセントカラー（macOS のシステムアクセント色に追従、またはプリセット／任意の色）、背景色・文字色（プリセット＋カラーピッカー）、本文フォント（システム／セリフ／ラウンド）と文字サイズ。背景・文字色はドキュメントだけでなく、サイドバーやツールバーを含むウィンドウ全体に反映されます。
- 複数の文書をサイドバーに並べて保持（BBEdit 風）：クリックで切替（一覧にフォーカスがあれば `↑`/`↓` でも切替）、丸い × で閉じる（`⌘W`）、`⌘1` でサイドバーを開閉。開いていたセットは次回起動時に復元。
- 一覧は読みたい順に並べ替え可能：行をドラッグ、または `⌘↑`/`⌘↓` で移動。`⌘` クリック・`⇧` クリックで複数行を選ぶと、まとめて 1 ブロックとしてドラッグ／移動できます。並び順もセッションと一緒に記憶。
- 「フォルダを開く」でフォルダ内の Markdown をまとめて閲覧：左のツリーからファイルを選んで切替、サブフォルダは展開／折りたたみできます。開いていたフォルダは次回起動時に復元。
- 見出しのアウトライン（目次）を本文の右に独立した列で表示：クリックでその見出しへスクロールし、読んでいる位置の見出しが自動でハイライトされます。`⌘2` で開閉、編集中も内容にライブ追従。本文に幅を譲るため**編集中は既定で非表示**ですが、`⌘2` で出せばそのまま覚えます（表示状態はプレビュー／編集それぞれで記憶）。設定（`⌘,`）で左サイドバー内に戻すこともできます（そのときは折りたたみ可）。
- 未保存の作業を失わない：編集中の内容（およびディスクに未書き出しの無題文書）は下書きとして継続的に保持され、次回起動時に復元。終了やクラッシュでも書きかけを失いません。
- ダブルクリックや「このアプリで開く」（対象拡張子のハンドラとして登録）、ボタン、`⌘O`、ウィンドウへのドラッグでファイルを開けます。
- 開いているファイルがディスク上で変更されると自動リロード（スクロール位置は保持）。
- スタート画面に最近使ったファイル一覧を表示し、素早く再オープン。
- 表、コードブロック、引用、ローカル画像をレンダリング（相対パスはファイル基準で解決）。
- **文書ヘッダー**：frontmatter にタイトル・文書番号・版数・日付・作成者・機密区分を書くと、文書の先頭に**帯**として描かれます（キー名は `タイトル` / `title` など日英どちらでも拾います）。ロゴは設定 ▸ 文書ヘッダーで一度登録すれば全文書に入ります。**プレビューに出るものがそのまま PDF に出ます。** 帯は先頭に一度だけ描きます——プレビューにはページの概念が無いので、全ページに繰り返すと画面と出力が食い違うためです。同じ理由で**ページ番号は入れられません**（CSS からページ番号を出す仕組みをブラウザ側が実装していないので、こちらから制御できません）。
- 上記以外の YAML frontmatter は、`tags:` などを本文に漏らさず、畳んだメタ情報カードとして表示。
- フェンス付きコードブロックを [highlight.js](https://highlightjs.org/) でシンタックスハイライト（共通バンドルを遅延読み込み、ダークテーマに調整）。
- ```` ```mermaid ```` コードブロック内の [Mermaid](https://mermaid.js.org/) 図をレンダリング（遅延読み込み、構文エラー時はソースにフォールバック）。
- 数式を [KaTeX](https://katex.org/) で組版（`$…$` はインライン、`$$…$$` はブロック。不正な式は例外を投げずそのまま表示）。脚注（`[^1]`）は末尾のセクションに相互リンク付きで描画。`- [ ]` / `- [x]` のタスクリストはチェックボックスで表示。
- **HTML として書き出す**（`⌘⇧E`）：レンダリング結果を自己完結した 1 枚の HTML に保存。スタイル・画像・（数式があれば）KaTeX のフォントまで埋め込むので、アプリの外でもそのまま開けます。
- **PDF として書き出す**（`⌘P`）：OS の印刷ダイアログを開き、「PDF として保存」で書き出します。印刷時は自動で白地・明るいコード配色に切り替わり、コードブロックや表・数式がページ跨ぎで割れません。
- リンクはアプリ内で完結：外部リンクはブラウザで開き、文書内アンカーはスクロール、ローカルの Markdown ファイルへのリンク（`[text](./other.md)`）はアプリ外に出ずそのままアプリ内で開きます。
- HTML 出力は DOMPurify でサニタイズし、厳格な CSP でロックダウン（信頼できないファイルも安全に開けます）。
- 現在のファイルを再読み込み（`⌘R`）。

## インストール

macOS 版（Apple Silicon / Intel、macOS 10.15 以降）のビルドを [Releases](https://github.com/MR-TABATA/MRDown/releases) ページからダウンロードできます。

バイナリは Apple Developer ID で署名・公証（notarization）済みなので、ダウンロードしてそのまま起動できます。

## 開発

```bash
npm install
npm run tauri dev
```

## ビルド

```bash
npm run tauri build
```
